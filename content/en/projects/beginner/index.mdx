# Beginner

These projects progress from the first cloud connection to sensors and remote actuator control. Complete them in order if you are new to ESP32.

| No. | Project                                                                    | Main concept                      |   Time |
| --: | -------------------------------------------------------------------------- | --------------------------------- | -----: |
|   1 | [Cloud Hello](/en/projects/beginner/01-cloud-hello/)                       | Wi-Fi, PxServ client, `setData()` | 15 min |
|   2 | [Remote LED](/en/projects/beginner/02-remote-led/)                         | `getData()`, digital output       | 20 min |
|   3 | [Button Counter](/en/projects/beginner/03-button-counter/)                 | Digital input, edge detection     | 25 min |
|   4 | [Potentiometer Monitoring](/en/projects/beginner/04-potentiometer/)        | `analogRead()`, `map()`           | 20 min |
|   5 | [Light Level](/en/projects/beginner/05-light-level/)                       | LDR voltage divider               | 25 min |
|   6 | [Temperature and Humidity](/en/projects/beginner/06-temperature-humidity/) | DHT11, validation                 | 30 min |
|   7 | [Door Status](/en/projects/beginner/07-door-status/)                       | Reed switch, state changes        | 25 min |
|   8 | [Motion Alarm](/en/projects/beginner/08-motion-alarm/)                     | PIR sensor, event counting        | 30 min |
|   9 | [Soil Moisture](/en/projects/beginner/09-soil-moisture/)                   | Analog calibration                | 30 min |
|  10 | [Remote Buzzer](/en/projects/beginner/10-remote-buzzer/)                   | Cloud command, safe output        | 25 min |

Read the [common setup and safety guidance](/en/projects/) before wiring a project.
